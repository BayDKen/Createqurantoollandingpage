## 2024-05-18 - Implement Route-Level Code Splitting\n**Learning:** React Router v7 supports route-level code splitting out of the box using the `lazy` property on route objects. When dynamically importing components with named exports, it is necessary to map the imported module to a `{ Component }` object (e.g., `.then(m => ({ Component: m.Page }))`) for the router to recognize it correctly.\n**Action:** Use this exact pattern `lazy: () => import("...").then(m => ({ Component: m.ExportName }))` whenever lazy loading named exports in React Router v7 to avoid routing errors.
