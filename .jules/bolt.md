## 2024-05-15 - React DnD List Re-renders\n**Learning:** When building drag-and-drop lists with `react-dnd`, parent container re-renders (triggered by hover/drop zone state changes) cause all draggable children to re-render. This is a common performance pitfall in this codebase.\n**Action:** Always wrap draggable child list items in `React.memo()` to prevent O(n) rendering bottlenecks during drag operations.
