## 2024-03-12 - React Router v7 Code Splitting\n**Learning:** The project uses React Router v7 which natively supports code splitting via the `lazy` property on route definitions without requiring manual `<Suspense>` boundaries. We can safely remove static imports and resolve dynamically loaded named exports directly to the route `Component`.\n**Action:** Use the `lazy` property over traditional `React.lazy` wrappers in this codebase to optimize bundle loading performance for routes.
